# E-Commerce Sales Analysis

## Project Overview
This project analyzes e-commerce sales data using Python to understand revenue trends, product category performance, and customer spending patterns.

## Objectives
- Analyze monthly sales trends.
- Calculate month-over-month revenue growth.
- Identify the best-performing product categories.
- Find the highest-spending customers.
- Calculate the revenue contribution of the top 10% of customers.
- Provide business recommendations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Information
This project uses a **synthetically generated dataset** containing:
- 2,000 orders
- Customer IDs
- Four product categories
- Order dates from 2025
- Order amounts

No real customer information is used.

## Project Steps
1. Data creation and exploration
2. Data cleaning checks
3. Date feature engineering
4. Monthly sales analysis
5. Sales growth analysis
6. Category-wise sales analysis
7. Pivot table and heatmap
8. Customer spending analysis
9. Business recommendations

## Key Learning Outcomes
- Data manipulation using Pandas
- Grouping and aggregation
- Date and time feature extraction
- Pivot table creation
- Data visualization
- Business insight generation

## Conclusion
This project helped me understand how Python can be used to analyze sales data, identify customer patterns, and support business decisions.
